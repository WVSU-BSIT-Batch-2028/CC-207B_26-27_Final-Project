# BahinKo

BahinKo is a Flutter app for sharing group expenses, tracking payments, and
managing recurring bills.

## Features

- Recurring bills with monthly due dates and due-soon notifications
- Activity history with filters and search, plus a personal ledger
- Group spending statistics and privacy settings
- Pull-to-refresh on supported screens

## Development

Run these commands from this directory:

```powershell
flutter pub get
dart analyze
flutter test
```

The current `lib/main.dart` opens the UI preview. Firebase startup and its
private configuration are not included in this project folder.
